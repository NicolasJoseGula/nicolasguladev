Bar chart race CSV format

Updated 2026-08-08 · Chart Maker for Mac

The layout, the column names that are recognised, and the two mistakes that make a finished chart look wrong.

The basic shape

A bar chart race needs a wide table: one row per competitor, one column per point in time. The first column carries the name; every column whose heading looks like a year, a season or a date is read as a point on the timeline.

Nation,ISO2,1924,1928,1932,1936
United States,us,1,2,4,4
Norway,no,,3,5,6
Austria,at,3,3,3,4

Headings that count as time: a plain year (1924), a season (1992-93, 2025/26), or a date (2026-03-01, 01/03/2026). Everything else is treated as a property of the competitor.

The optional columns

RoleCall the columnWhat it does
NameName, Nation, Country, Team, Club, Company, PlayerThe label on the bar
Flag codeISO2, ISO, Code, Country CodeDraws a bundled round flag
PictureImage, Logo, Badge, Crest, Photo, IconA web address, drawn on the bar
GroupRegion, Continent, Group, Category, LeagueColours the bars and fills the legend
Short nameShort, Abbr, AbbreviationUsed in the vertical cut only

Matching is case-insensitive and none of these are required — a file with nothing but a name column and some years works. If a column is not recognised, the app says so: View data lists every role it looked for, which heading answered to it, and which found nothing.

Mistake one: zeros where there is no reading

A zero is a statement — it says this competitor was in the race and had none. A blank says it was not in the race yet. If you fill your blanks with zeros, every future competitor sits on the baseline from the first frame, and a chart that should start with three bars starts with forty.

Mistake two: the wrong kind of number

Decide whether your column is a running total or a per-period figure. Medals won in total by 1936 and medals won during 1936 are different charts. In a spreadsheet a running total is one SUM away.

What the reader copes with on its own

  • Commas, semicolons, tabs or pipes as the separator — detected, not asked about.
  • Quoted fields containing commas: "Korea, Republic of".
  • Both thousands conventions, guessed per cell: 1,234.56 and 1.234,56.
  • Currency symbols, per-cent signs and spaces used as group markers.
  • Accounting parentheses for negatives: (1200).
  • n/a, NA, null and - as “no reading”.
  • Windows line endings and Excel’s byte order mark.

How many rows can it take?

As many as you like. On import, a row is kept if it reaches the top at any single point in time — a few places deeper than the bars on screen — and the rest are dropped with a note saying how many. That keeps every overtake while sparing the render two hundred competitors who were never in shot.

Questions

Can I use dates instead of years?

Yes. Dates in yyyy-MM-dd, dd/MM/yyyy, MM/dd/yyyy and yyyy-MM are all recognised, as are seasons like 2025/26.

Does the first column have to be called Name?

No. If no column announces itself, the first column that is not a point in time is taken as the name.
