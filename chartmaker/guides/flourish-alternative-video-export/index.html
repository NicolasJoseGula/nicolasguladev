A Flourish alternative for people who need the video file

Updated 2026-08-08 · Chart Maker for Mac

Flourish is very good at what it is for. If what you need is an MP4, it is the wrong end of the tool.

The specific gap

Flourish is a fine way to build an interactive bar chart race and embed it in an article. But video export is not part of the ordinary plans, it belongs to an enterprise contract, so creators who need a file to upload end up screen-recording the animation in a browser window. Every tutorial that says “now record your screen” is describing that gap.

Where the browser tools are still better

Be honest about this before you switch. If you want an interactive chart embedded on a web page, where a reader can hover a bar and read a tooltip, a browser tool is the right answer and this app is not: it makes video files. If you need Windows or Linux, this app is macOS only. And if you want to redesign every element of the chart, this app deliberately does not let you: it ships three looks taken from published videos, and what it sells is that the choices are already made.

Moving your data across

Nothing to convert. The wide CSV a browser tool wants (one row per competitor, one column per point in time) is the same shape this app reads, so the file you already have imports as it is.

Try it against your own file first

The app is free and the free version exports at full resolution: it signs the video with a small mark, which is enough to see whether the output is what you want before any money changes hands.

Questions

Can I import my Flourish data straight in?

Yes. The wide CSV layout is the same, so the file you prepared for a browser tool imports without changes.

Is there a Windows version?

No. It is a native app for Mac, iPad and iPhone: macOS 14, iPadOS 17 or iOS 17.
