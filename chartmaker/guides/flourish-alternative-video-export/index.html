A Flourish alternative for people who need the video fileUna alternativa a Flourish para quien necesita el archivo de video

Updated 2026-08-08 · Chart Maker for MacActualizado 2026-08-08 · Chart Maker para Mac

Flourish is very good at what it is for. If what you need is an MP4, it is the wrong end of the tool.Flourish es muy bueno en lo suyo. Si lo que necesitás es un MP4, es la punta equivocada de la herramienta.

The specific gapEl hueco puntual

Flourish is a fine way to build an interactive bar chart race and embed it in an article. But video export is not part of the ordinary plans — it belongs to an enterprise contract — so creators who need a file to upload end up screen-recording the animation in a browser window. Every tutorial that says “now record your screen” is describing that gap.Flourish es una gran forma de armar un bar chart race interactivo e incrustarlo en una nota. Pero la exportación de video no está en los planes comunes — es parte de un contrato enterprise — así que quien necesita un archivo para subir termina grabando la pantalla con la animación en una ventana del navegador. Todo tutorial que dice “ahora grabá tu pantalla” está describiendo ese hueco.

Where the browser tools are still betterDónde las herramientas web siguen siendo mejores

Be honest about this before you switch. If you want an interactive chart embedded on a web page, where a reader can hover a bar and read a tooltip, a browser tool is the right answer and this app is not — it makes video files. If you need Windows or Linux, this app is macOS only. And if you want to redesign every element of the chart, this app deliberately does not let you: it ships three looks taken from published videos, and what it sells is that the choices are already made.Sé honesto con esto antes de cambiar. Si querés un gráfico interactivo incrustado en una página web, donde el lector pueda pasar el mouse por una barra y leer un tooltip, una herramienta web es la respuesta correcta y esta app no — esta app hace archivos de video. Si necesitás Windows o Linux, esta app es sólo macOS. Y si querés rediseñar cada elemento del gráfico, esta app a propósito no te deja: trae tres estilos tomados de videos publicados, y lo que vende es que las decisiones ya están tomadas.

Moving your data acrossMudar tus datos

Nothing to convert. The wide CSV a browser tool wants — one row per competitor, one column per point in time — is the same shape this app reads, so the file you already have imports as it is.No hay nada que convertir. El CSV ancho que quiere una herramienta web — una fila por competidor, una columna por punto en el tiempo — es la misma forma que lee esta app, así que el archivo que ya tenés se importa tal cual.

Try it against your own file firstProbalo primero con tu propio archivo

The app is free and the free version exports at full resolution — it signs the video with a small mark, which is enough to see whether the output is what you want before any money changes hands.La app es gratis y la versión gratis exporta a resolución completa: firma el video con una marca chica, que alcanza para ver si el resultado es lo que querés antes de que cambie de manos un peso.
