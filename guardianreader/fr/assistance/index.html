Guardian Reader pour iPhone

Problèmes fréquents

L'app dit qu'elle n'a pas entendu mon enfant lire

Vérifiez que l'autorisation du microphone est activée dans les Réglages, que la pièce n'est pas trop bruyante, et que l'enfant lit à un volume de conversation normal plutôt qu'en chuchotant. Si la page a été scannée avec une partie de la page d'en face dans le cadre, le texte cible sera plus long que ce qui est lu ; rescannez avec la page entière dans le repère.

Le scan a capté du texte de l'autre page

Seul ce qui se trouve dans le cadre à l'écran est utilisé. Rapprochez le téléphone ou recadrez pour qu'une seule page remplisse le repère, puis vérifiez l'écran de confirmation, qui montre exactement le texte qui servira avant le début de la lecture.

Les apps ne se sont pas reverrouillées

Le reverrouillage se fait automatiquement à l'expiration des minutes gagnées. Assurez-vous que l'accès au Temps d'écran est toujours autorisé dans les réglages de l'app, et que les apps attendues sont toujours sélectionnées. Le plus court intervalle de récompense accepté par le système est de 15 minutes.

J'ai oublié mon code parental

Pour des raisons de sécurité, le code n'est conservé que sous forme d'empreinte cryptographique et ne peut être ni récupéré ni réinitialisé par nous. Supprimer l'app ne l'efface pas non plus : iOS conserve les éléments du trousseau après la suppression d'une app, donc une réinstallation sur cet iPhone redemande le même code. Ce que la suppression efface, c'est l'historique de lecture. Tant que vous y avez encore accès, vous pouvez changer le code dans Réglages, Sécurité, Modifier le code parent. S'il est déjà perdu, le seul moyen de l'effacer est de réinitialiser l'iPhone dans Réglages, Général, Transférer ou réinitialiser l'iPhone, Effacer contenu et réglages.

Faut-il lire une page à la fois ?

Non. Scannez d'abord toutes les pages de la séance, une photo par page, puis lisez-les toutes à voix haute d'une traite. L'app compare la lecture à tout ce que vous avez scanné : enchaîner d'une page à l'autre est exactement ce qu'elle attend.

Restaurer un achat

Ouvrez l'écran Premium et touchez Restaurer. Les achats sont liés au compte Apple qui les a effectués.

Configuration requise

iPhone sous iOS 18 ou version ultérieure. Disponible en 9 langues : français, anglais, espagnol, portugais, allemand, italien, japonais, coréen et chinois.
